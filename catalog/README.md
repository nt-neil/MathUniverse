## 2020 年代狀態變動精選

首輪建檔查證到、多數舊清單尚未更新的重大變動(詳見各領域檔的「值得關注的動態」節):

- **掛谷猜想 3 維情形已證**(Wang–Zahl 2025,預印本;Hong Wang 獲 2026 Fields 獎)
- **雅可比猜想出現宣稱反例**(Alpöge 2026-07-20,n≥3,⚠️ 未經審查)
- **Brauer 高度零猜想**(2024)與 **McKay 猜想**(2026)刊出,兩大表示論長期猜想落幕
- **Kaplansky 單位猜想被否證**(Gardam 2021)
- **希爾伯特第十問題(數域整數環版)被否定解決**(2024)
- **4 維 Ising 平凡性已證**(Aizenman–Duminil-Copin 2021)
- **Odd Hadwiger 猜想被否定**(2025-12,預印本);**隨機化 k-server 猜想被否證**(2023)
- **Quine NF 一致性**經 Lean 形式化驗證落幕(2024)
- **Ramsey 數上下界雙突破**(2023–2025);**Kelley–Meka** 等差數列突破(2023)
- **矩陣乘法指數現行最佳界 ω < 2.371339**(2024)
