# MSC2020 完整分類樹

Mathematics Subject Classification 2020(MSC2020)由 Mathematical Reviews(AMS)與 zbMATH 共同維護,是國際通用的數學文獻分類系統。

本目錄收錄完整分類:**63 個一級分類**、**534 個二級分類**、**5503 個三級條目**(另有 503 個 `##-##` 形式的通用條目,如教科書、綜述、歷史、計算方法等,列於各一級分類檔開頭)。

三級條目描述保留英文原文;一級分類附繁體中文譯名。
