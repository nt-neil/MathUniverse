# 數學研究領域地圖(MSC 分類概覽)

「數學研究主題有多少?」其實沒有一個固定數字。現代數學已經發展出數百個研究方向、數千個細分領域。目前國際上最常用的分類系統是 **Mathematics Subject Classification(MSC)**,由美國數學學會(AMS)與德國 zbMATH 維護:

- 約 **63 個一級分類**
- 超過 **500 個二級分類**
- 超過 **6,000 個三級研究主題**

也就是說,全世界的數學研究已經細分成數千個方向,而且每年仍持續細分並誕生新方向。

## 主要大領域

| 領域 | 研究內容 |
|---|---|
| 代數 (Algebra) | 群、環、域、表示論 |
| 幾何 (Geometry) | 微分幾何、代數幾何、拓樸 |
| 分析 (Analysis) | 微積分、傅立葉分析、泛函分析 |
| 數論 (Number Theory) | 質數、密碼學 |
| 拓樸 (Topology) | 空間的本質 |
| 微分方程 (PDE/ODE) | 自然現象、流體、物理 |
| 機率論 (Probability) | 隨機過程、金融 |
| 組合學 (Combinatorics) | 圖論、最佳化 |
| 離散數學 (Discrete Math) | 演算法、計算理論 |
| 邏輯 (Logic) | 可計算性、證明理論 |
| 數值分析 (Numerical Analysis) | 科學計算 |
| 最佳化 (Optimization) | AI、機器學習 |
| 數學物理 (Mathematical Physics) | 相對論、量子力學 |
| 動態系統 (Dynamical Systems) | 混沌、控制 |
| 統計學 (Statistics) | 推論、資料分析 |

## 近十年的熱門方向

- 調和分析(Harmonic Analysis)— 掛谷猜想就在這裡
- 代數幾何(Algebraic Geometry)
- 朗蘭茲綱領(Langlands Program)
- 幾何群論(Geometric Group Theory)
- 隨機矩陣(Random Matrices)
- 最佳傳輸(Optimal Transport)
- 幾何分析(Geometric Analysis)
- AI 數學(Optimization、Learning Theory)
- 計算數學(Computational Mathematics)
- 密碼學(後量子密碼 Post-Quantum Cryptography)
