# 目錄檔格式規範(Catalog file format)

`catalog/` 下每個領域一檔,收錄該領域的著名未解(或近年才解決的)問題。

## 檔案結構

```markdown
# 〔領域名 English Name〕未解難題目錄

> 一句話說明本領域與收錄範圍。

**主要來源**:列出本檔依據的清單/資料庫(附連結)。

## 難題清單

| 難題 | 問題(一句話) | 提出 | 狀態 | 來源 |
|---|---|---|---|---|
| 中文名(English Name) | 直觀的一句話陳述 | 年份/提出者 | 見下方標記 | [連結] |

## 值得關注的動態

近 5 年(2021–2026)本領域被解決、或有重大進展的問題,每條附可查證來源。
```

## 狀態標記(統一使用)

- `未解` — 完全開放
- `部分解決` — 特例已證(括號註明,如「3 維已證」)
- `✅ 已解決(年份)` — 含 2020 年代新解決的,附來源
- `⚠️ 宣稱證明` — 有未經審查/有爭議的宣稱,不算解決

## 鐵律

1. 每一列的「來源」必須是可查證連結(Wikipedia 條目、arXiv、Open Problem Garden、期刊)。
2. 狀態必須經查證——清單類來源常過時,近年已解決的問題要標出來。
3. 預印本(preprint)一律註明;宣稱解決但未被學界接受的,標 `⚠️`。
4. 繁體中文為主,難題名稱附英文原名。
5. 已在 `problems/` 有完整檔案的難題,來源欄改連到該檔(相對路徑)。
